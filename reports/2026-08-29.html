YingMusic-Singer: Controllable Singing Voice Synthesis with Flexible Lyric Manipulation and Annotation-free Melody Guidance

無須手動對齊：以音色參考、旋律人聲與改寫歌詞三輸入做擴散式唱聲合成，並提出 LyricEditBench 評測保旋律改詞。

可轉譯 singing voice lyric editing melody control
Insight

洞見:karaoke-jp 若要「改詞但留原曲旋律／音色」，最大摩擦常是手動對齊與可控性不足——要麼只能整段重唱，要麼卡在音素對齊標註。YingMusic-Singer 把任務收成三輸入：可選音色參考、提供旋律的人聲片段、改寫後歌詞，全程不需手動對齊；以純擴散架構搭配 curriculum learning 與 Group Relative Policy Optimization，在旋律保留與歌詞遵從上勝過可比的無對齊基線 Vevo2，並釋出 LyricEditBench 作為首個「保旋律改詞」基準。程式、權重、基準與 demo 已公開（ASLP-lab/YingMusic-Singer-Plus）。對 karaoke-jp：這是「LRC／歌詞編輯 → 保旋律重唱」的直接模板，可接在人聲分離與歌詞對齊之後，做 JPOP 練習軌的局部改詞實驗，而不必先建完整 mora 對齊標註管線。

Try next

可做:取一首 JPOP 分離人聲，改寫一句日語歌詞，跑 YingMusic-Singer 對照 Vevo2；用 LyricEditBench 指標或人工聽感檢查旋律漂移與歌詞可懂度，再決定是否接上既有 LRC 渲染。

重要度

Problem

既有唱聲合成若要改詞並保留旋律，往往可控性不足，或依賴費力的手動對齊／精細標註。

Method

提出全擴散式 YingMusic-Singer：以可選音色參考、旋律人聲與改寫歌詞為輸入，無需手動對齊；採 curriculum learning 與 GRPO 強化旋律保留與歌詞遵從。

Data

Findings

在旋律保留與歌詞遵從上優於可比無對齊基線 Vevo2；公開基準與權重，使「保旋律改詞」可被複現與對齊比較。

Limitations

初版為 2026-03、更新至 2026-07，非本週全新稿；摘要未展開大規模日語 JPOP／kana-ruby 專項數字；實務上仍需自行驗證分離人聲品質與日語音素邊界。

FlowSep 2: Self-Supervised Flow Matching for Language-Queried Audio Source Separation

以文字查詢做音源分離：用 rectified flow matching + DiT 在潛空間生成目標源，並以 Self-Flow 自監督強化語義結構。

貼近主線 flow matching source separation text query
Insight

洞見:MeanAudio 與 karaoke-jp 都常卡在「遮罩式分離」：重疊事件時目標被過度壓制或分離不全，而語言查詢（LASS）本應比固定 stem 類別更靈活。FlowSep2 不預測 mask，改以 text-conditioned rectified flow matching，在潛空間從高斯噪聲生成目標源表徵，條件同時吃混音表徵與文字查詢，骨幹為 Diffusion Transformer；再導入 Self-Flow 自監督流匹配，讓潛空間在生成目標下更有語義結構。多個 LASS 基準顯示 SOTA，重疊場景分離更穩。對 MeanAudio：這是「rectified flow + 語言條件分離」的完整配方，可對標既有 mask／Demucs 管線；對 karaoke-jp：可用自然語言指定「主唱／和聲／特定音色」做第二段條件抽取，補昨天 singer enrollment 分離之外的文字介面。

Try next

可做:在 JPOP 混音上用中／英／日語 query（如「lead vocal」「female harmony」）跑 FlowSep2，對照 Demucs／BS-RoFormer 的 SI-SDR 與下游歌詞 ASR WER；再試 Self-Flow 有無的消融。

重要度

Problem

多數語言查詢音源分離仍用判別式 mask，重疊複雜場景易過度壓制目標或分離不全。

Method

提出 FlowSep2：以文字與混音條件的 rectified flow matching（DiT）在潛空間生成目標源；並以 Self-Flow 自監督強化語義結構化表徵。

Data

多個 LASS 基準評估；著重重疊聲事件場景；投稿 IEEE/ACM TASLP；更新於 2026-08-25。

Findings

於多個 LASS 基準達 SOTA；在重疊聲事件的困難場景展現更佳分離效果。

Limitations

摘要未給日語唱詞／商業 JPOP 專項數字；生成式分離延遲與即時性未在摘要展開；Self-Flow 對音樂人聲的外推需自行驗證。

Editor Note

MeanAudio 本週硬貨：rectified flow LASS——語言條件生成式分離，可同時服務 T2A 混音診斷與 karaoke 條件抽人聲。
