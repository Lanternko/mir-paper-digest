Training-Free Pronunciation Transcription via Text-Constrained Acoustic Rescoring

用辭典與 G2P 先列出受文字約束的候選讀音，再拿凍結的語音模型算整句對數機率挑選，不必訓練就把三個日文語料的發音字元錯誤率壓到 0.04–0.17%。

可轉譯 日文發音轉寫 G2P/S2P 融合 免訓練 rescoring
Insight

洞見：日文讀音的難點不是聲學不夠好，而是候選空間沒被文字約束住；先用辭典把候選收斂成有限集合，再讓聲學模型只做排序，就能把 ST2P 從「需要標註訓練」變成「推論期組裝」。

Try next

可做：在 karaoke-jp 的 kana/ruby 階段插一個同款 rescorer——用歌詞文字經 G2P 產生候選讀音（含連濁、助詞は/へ的讀法、外來語片假名），再用現有唱聲 S2P 模型對每個候選算整句 NLL 選最佳，先在 20 首歌上量 kana CER 與人工校正次數。

重要度

Problem

大規模製作 TTS（以及卡拉 OK 歌詞）訓練資料時需要準確的發音（讀音）轉寫。純文字的 G2P 無法解決同形異讀，純語音的 S2P 缺少詞彙知識，而同時吃文字與語音的 ST2P 模型則需要昂貴的發音標註資料才能訓練。

Method

提出免訓練的 ST2P 流程：先用辭典資源與 G2P 工具為輸入文字生成「受文字約束」的候選讀音集合，再以 left-to-right 貪婪搜尋，用凍結的預訓練 S2P 模型給出的整句 negative log-likelihood 當分數逐步選定最佳候選。整體是 cascade（先文字候選、後聲學排序），不更新任何模型權重。

Data

三個日文語料，分別在「參考轉寫（reference transcripts）」與「ASR 轉寫」兩種條件下評估；另外在西班牙文、法文與初步的英文上測試跨語言可遷移性。基線包含純文字方法、已訓練的 ST2P 模型，以及商用／開源多模態 LLM。

Findings

日文 CER 由純文字基線的 0.60–1.40% 降到 0.04–0.17%（用參考轉寫），改用 ASR 轉寫時為 0.64–1.58%；優於所有基線，包括一個已訓練的 ST2P 模型與商用多模態 LLM。貪婪搜尋在相近 CER 下比 beam search 快 3–3.5 倍，cascade 比直接解碼快 2 倍。西班牙文、法文與初步英文也勝過四個開源多模態 LLM 與最佳傳統方法。

Limitations

誠實標注：改用 ASR 轉寫後誤差回升到接近純文字基線的量級（0.64–1.58%），也就是說增益高度依賴文字端的品質——而卡拉 OK 場景的歌詞辨識正是最不穩的一環。方法本身依賴辭典與 G2P 覆蓋率，候選不在集合裡就救不回來；論文評估的是朗讀／語音語料，沒有唱聲資料，英文結果作者自稱是 preliminary。

Editor Note

這篇對 karaoke-jp 幾乎是現成零件：它把「文字候選 × 聲學排序」拆成兩個可以各自替換的模組，前半段可以換成你現有的 kana/ruby 規則，後半段可以換成唱聲模型。但別忘了它的前提是文字正確；在歌詞先過 ALT 的 pipeline 裡，要先量一次歌詞辨識錯誤如何傳導到讀音錯誤。

Don't CLAP: Are Music-Text Models Bag-of-Words?

把 caption 裡兩個樂器的音色、主副角色或出現順序互換一次，四個對比式 music-text 模型都分不出原版與改版，顯示 CLAP score 更像 bag-of-words 而非真的在讀文字語意。

貼近主線 CLAP score 可信度 music-text 對比模型 屬性綁定評估
Insight

洞見：CLAP score 之所以看起來「有效」，可能只是因為它抓到了 caption 的詞袋分佈；一旦擾動保持詞彙不變只換綁定關係，分數就失去區辨力——也就是說用 CLAP 當 faithfulness 指標，等於用一個對語意不敏感的尺去量語意對齊。

Try next

可做：在 MeanAudio 的評估腳本裡加一組 attribute-swap 對照——對每條測試 caption 產生一個只交換兩樣樂器音色（或主副關係）的變體，回報 CLAP 在原版與變體上的分差；若分差接近 0，就在報告裡改用成對人評或屬性級分類器當 faithfulness 主指標，CLAP 只留作輔助。

重要度

Problem

text-to-music 系統的 prompt 忠實度幾乎都用 CLAP score（music-text 模型的音訊與文字嵌入餘弦相似度）當客觀指標。但這個分數究竟有沒有真的讀懂文字——尤其是「某個屬性綁在某個樂器上」這種細粒度語意——一直沒有被系統性檢驗。

Method

提出 attribute swap 擾動：取真實錄音的 caption，只交換兩個樂器之間的一項屬性——音色（timbre）、主奏 vs 伴奏、或首次出現的順序——產生一個詞彙幾乎相同但語意被改變的對照 caption。然後測試四個對比式 music-text 模型與一個大型 audio-language model，看音訊對原版 caption 的分數是否高於對擾動版。

Data

以真實錄音及其 caption 為基礎，人工／程序化生成成對的原版與屬性互換版 caption；受測對象為四個對比式 music-text 模型與一個 large audio-language model。另有後續實驗用來拆解 audio-language model 的優勢來自聲學還是語言先驗。

Findings

沒有任何對比式模型能穩定分辨原版與擾動版 caption。audio-language model 表現較好，但進一步實驗顯示它的優勢主要來自與音訊無關的語言先驗（audio-agnostic language priors），而不是真的聽出差別。作者因此主張 CLAP score 及相關指標無法捕捉細粒度音樂語意與屬性綁定，其表徵接近 bag-of-words。

Limitations

誠實標注：擾動只涵蓋三種屬性（音色、主副、出現順序），是否能推廣到節奏、調性、情緒等維度沒有驗證；受測模型只有四個對比式模型加一個 ALM，沒有覆蓋所有常用 CLAP 變體。這是診斷性研究，只說明指標不可靠，沒有提出替代指標，也沒有回答「換成什麼分數才對」。

Editor Note

對 MeanAudio 的直接影響是：如果你的實驗表在用 CLAP 當 prompt 忠實度的主要證據，這篇提供了一個便宜的自我檢查（跑一次 attribute swap 看分差）。同時也提醒 reward alignment 的風險——拿 CLAP 當 reward，模型可能只學會湊詞袋。
