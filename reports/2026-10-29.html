What Do Audio-Language Judges of Generated Music Listen For? Four Probes with Controls from Expert Ratings

拿開源音訊語言模型當生成音樂的評審前，先用四種探針檢查它到底在聽音訊、看 prompt，還是被題目措辭與順序牽著走。

貼近主線 music evaluation audio-language judge MusicEval
Insight

洞見:用音訊語言模型當音樂生成的評審已很常見，但只看與專家評分的相關性，分不出評審究竟在回應音訊、prompt 還是問法。作者設計四個探針：拿掉音訊、換成另一模型對同一 prompt 的音訊、對調成對比較的順序、改寫指令，並用人類評分算出對照基準。在 MusicEval 全部 2,748 段音樂上測五個開源評審：沒有音訊時沒有任何評審勝過『只靠 prompt 預測』的基準；有音訊時所有評審在 prompt 對齊上確實跟著所聽到的片段走，但音樂品質只有兩個做到；四個較小評審的成對判斷受位置影響多於品質；改寫指令對品質相關性的影響約等於換一個評審。對 MeanAudio 這類以 CLAP／FAD 與 reward alignment 為核心的流程，這直接提醒：用音訊語言模型當 reward 或評分器前，要先做這些對照。限制：只測開源評審與 MusicEval／SongEval，結論是否推廣到更強的閉源評審未知，且 MusicEval 的 prompt 分配本身就限制了純 prompt 評審的上限。

重要度

Problem

音訊語言模型常被當作生成音樂的評審，但與專家評分的相關性無法說明它是否真的在聽音訊，還是被 prompt 或題目措辭影響。

Method

提出四個探針（移除音訊、替換為其他模型對同一 prompt 的片段、對調成對比較順序、改寫指令），其中三個與由人類評分算出的對照基準比較，並建議評審報告都附上這四項。

Data

五個開源音訊語言模型評審；MusicEval 全部 2,748 段音樂；後兩個探針另用 SongEval 歌曲。

Findings

無音訊時無評審勝過只靠 prompt 的基準；有音訊時皆跟隨片段的 prompt 對齊，僅兩個在音樂品質上做到；四個小評審成對判斷受位置影響多於品質；改寫指令對品質相關性的影響約同於換評審。

Limitations

只測五個開源評審與 MusicEval／SongEval；MusicEval 的 prompt 分配限制模型層級的純 prompt 評審表現；10 頁含 15 個表，未涵蓋閉源評審與其他語言。

Editor Note

想用音訊語言模型當 reward 或評分器的人必讀：先確認它真的在聽，也要注意措辭與順序偏誤。

Restore, Separate, Restore: A Modular Framework for Music Source Restoration

音樂音源修復不只分離，還要還原被 EQ、壓縮與編碼破壞的原始 stem；三階段流程先修復混音、再分成八個 stem、最後做 stem 專屬修復。

可轉譯 source restoration source separation vocals
Insight

洞見:一般音源分離假設混音是 stem 的線性相加，但真實發行的母帶還經過 EQ、壓縮等非線性處理與編碼損失。這篇把問題定義為 Music Source Restoration：目標是還原未經處理的原始樂器 stem。作者提出三階段模組化流程：先用混音修復模型清掉劣化，再用單一模型把修復後的混音分成八類（人聲、吉他、鍵盤、合成器、貝斯、鼓、打擊、管弦），最後對每個 stem 用針對分離殘留瑕疵微調的專家模型修復。摘要稱每一階段在 MSR Challenge 測試集上都比前一階段更好，程式碼與模型公開。對 karaoke-jp，人聲 stem 的乾淨度直接影響後面的歌詞對齊與唱聲 pitch 估計，特別是舊歌或壓縮嚴重的日文歌曲；這提供一條分離之後再修復人聲的思路。限制：摘要沒有給具體指標數字，也未說明人聲修復對下游對齊或轉錄的實際幫助。

重要度

Problem

標準音源分離無法處理母帶中的非線性製作效果（EQ、壓縮）與傳輸劣化（編碼瑕疵），因此得不到未經處理的原始 stem。

Method

三階段流程：混音修復模型、八 stem 分離模型（含人聲）、針對分離殘留瑕疵微調的 stem 專屬修復專家；每一階段依序改善。

Data

MSR Challenge 測試集；八類 stem：人聲、吉他、鍵盤、合成器、貝斯、鼓、打擊、管弦。

Findings

摘要稱每個階段在 MSR Challenge 測試集上都比前一階段進步；程式碼與模型已公開。

Limitations

摘要未提供具體指標數字與頁數；未評估對歌詞對齊、轉錄等下游任務的幫助；是否涵蓋日文歌曲或歌聲特性也未說明。

給 karaoke pipeline 的人聲前處理新選項，且有公開程式碼可試；數字與下游效益要讀全文才能確認。
