SoulX-Singer: Towards High-Quality Zero-Shot Singing Voice Synthesis

SoulX-Singer 以 4.2 萬小時唱聲訓練 flow matching DiT，同時支援 MIDI 樂譜與 F0 旋律控制，並釋出嚴格零樣本評測基準。

可轉譯 zero-shot SVS flow matching MIDI control
Insight

洞見:近期零樣本 SVS（Vevo2／YingMusic-Singer）多走「從現成歌抽旋律」路線，缺 note-level duration，歌詞與伴奏容易對不齊。SoulX-Singer 把工業部署缺口講清楚：資料升到約 42k 小時（國語／英語各約 20k、粵語約 2k），pipeline 先做 lead vocal 分離＋去殘響、語種辨識後歌詞轉錄、ROSVOT note 轉錄，再以 note 為單位（text／pitch／rest／lyric／slur）對齊。模型是 NAR flow matching DiT：長度調節器把 note 級條件展到 mel 時間軸；訓練時隨機 drop note pitch 或 F0，推論可切 score-control（純 MIDI＋歌詞）或 melody-control（F0＋歌詞）。對 karaoke-jp：這幾乎是「分離→歌詞→MIDI／pitch→可對齊唱聲」的參考端到端；mora-to-note／LRC 若要合成示範軌，score-control 比純旋律驅動好接。對 MeanAudio：flow matching＋雙條件門控、兩階段短句／長句訓練，可對照自家可控生成。限制是語言軸未含日語，日文 kana／ruby 需另接。

Try next

可做:用官方權重在 JPOP 混音上跑 score-control（外部 MIDI＋假名／羅馬字歌詞）與 melody-control（抽出 F0），量 intelligibility／對齊誤差，並把其分離＋ROSVOT 注記管線對照自家 karaoke-jp 資料清洗。

重要度

Problem

開源 SVS 仍難工業部署：資料規模小、零樣本弱，且近期旋律驅動系統缺少 note duration，導致唱詞與伴奏時序難對齊。

Method

大規模注記管線（分離／去殘響／歌詞與 note 轉錄）＋ flow matching DiT；長度調節對齊 note 與 mel；雙門控支援 MIDI 樂譜或連續 F0；兩階段短段／長段訓練。

Data

約 42,000 小時唱聲（國語／英語／粵語）；評測含 GMO-SVS（公開語料重組）與 SoulX-Singer-Eval（50 名未見歌手、note-level 標註、訓練－測試嚴格分離）。

Findings

在多語與多樣音樂條件下報告 SOTA 級合成品質；統一框架可做音色克隆、風格遷移與歌詞／樂譜編輯；並提供可重現的零樣本評測協議。

Limitations

訓練語言未含日語；技術報告細節與外部複現成本仍高；旋律／樂譜品質依賴上游分離與 ROSVOT；與完整 karaoke LRC／ruby 下游尚未串接驗證。

Editor Note

當月新文偏語音時，選這篇「重要但稍舊」的開源零樣本 SVS——直接服務 karaoke-jp 的 MIDI／對齊／唱聲主線。

Auditory Illusion Benchmark for Large Audio Language Models

AIB 是首個針對大型音訊語言模型的聽覺錯覺基準：十種音樂／聲響／語音錯覺，對照人類聽感，檢驗是否具備類人先驗。

MIR 觀點 LALM benchmark auditory illusion music perception
Insight

洞見:Music Flamingo／LALM 評測多停在辨識與問答正確率，很少問「模型會不會像人一樣聽錯」。首爾大學提出 AIB：十種經典聽覺錯覺（含 missing fundamental、Shepard tone、Risset rhythm、speech-to-song 等），分物理驅動與物理＋知識先驗，跨音樂／聲響／語音；完整集約 1.48 萬刺激，另有 mini set。指標拆 Human-Likeness Accuracy、Reality Alignment 與 Illusion Susceptibility Index，並用 20 名絕對音感聽者做人基線。結果：低階聲學錯覺上多數模型偏訊號忠實、人類則高度易感；牽涉語言／音樂先驗時部分模型較像人，但沒有模型貼齊人類剖面。對 Music Flamingo／音樂理解：可把 Shepard／speech-to-song 當「感知對齊」壓力測，而不只考 caption／標籤。對 karaoke-jp：speech-to-song 與音高錯覺直接關係「怎麼聽成歌／怎麼判音高」。

可做:把 AIB mini set（或 Shepard／speech-to-song 子集）接到 Music Flamingo／自家 LALM，報 HLA／RA／ISI；並用同一刺激測唱聲 pitch 估計是否被 missing fundamental 類錯覺帶偏。

重要度

Problem

現有音訊／多模態基準幾乎都綁客觀標籤，無法檢驗大型音訊語言模型是否內化人類聽感偏誤與錯覺。

Method

整理十種錯覺並標機制與領域；生成錯覺／對照刺激；改寫成二／三選一感知題；對多個 LALM 與人類聽測對齊，報 HLA、RA、ISI。

Data

完整集 10,385 錯覺＋4,444 對照（共 14,829）；mini set 1,566；人類基線為 20 名絕對音感聽者多數決；程式與刺激產生器開源。

Findings

物理錯覺上模型多偏訊號、人類易感；知識／音樂／語言先驗類錯覺上部分模型較接近人，但整體無人形剖面；顯示高階先驗與低階聽覺處理可能脫鉤。

Limitations

排除雙耳生理依賴錯覺；人類樣本限絕對音感者、規模不大；選擇題格式簡化了開放式感知；ICASSP 短文對個別模型細節有限。

Editor Note

給 Music Flamingo 路線補一塊「感知對齊」評測，而不只堆正確率。
