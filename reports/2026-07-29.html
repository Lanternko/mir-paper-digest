Neural Morphing: Sequence-Optimized Token-Level Morphing in Neural Audio Codecs

免訓練的 codec token 域音色 morph：RVQ 粗／中／細分組轉移＋連續性約束 beam 選 palette grain，解碼成「保節奏、換音色」的 VST3/AU 即時效果。

貼近主線 neural codec RVQ editing audio morphing
Insight

洞見:MeanAudio 的 neural codec 不只服務壓縮與生成 tokenizer，還能當可編輯的創作中間表示。Neural Morphing 把 DAC 的 9 層 RVQ 切成 coarse／middle／fine，只謹慎替換中高頻殘差、以 beam 抑制 palette 檔案間跳動——這等於把「codec latent 可操作」從論文想法落成 DAW 可調的 structure/detail 軸。對生成後編輯、stem 上色、或 MeanAudio 下游做 training-free 風格轉移，都比再訓練一個 conditional generator 更輕。

Try next

可做:固定 DAC 權重，用 JPOP 鼓／人聲 loop 當 source、環境或合成音當 palette，掃 ρ 與 beam width 聽 envelope 與 chattering；可對照昨日 HARP 的 stage 頻帶階層，看 coarse gate 是否與頻帶語意對齊。

重要度

Problem

創意音訊 morph 常卡在「保 source 節奏結構、又要 palette 音色細節」：古典頻譜 morph 與 waveform mosaicing 難接 DAW 即時工作流，而多數 latent 編輯又需要為每個 palette 重訓模型。

Method

以預訓練 neural codec（主實驗 DAC 44.1 kHz、9 codebook）將 source 與 palette 編碼為 token grain；用 codec 誘導 descriptor 做近鄰檢索；RVQ-group transfer 分組處理粗／中／細 codebook；連續性約束下以 bounded beam search 取代逐 grain 貪婪選擇；JUCE 實作 VST3/AU 與 chunked realtime 路徑。

Data

評估以確定性 manifest：247 段 Freesound Creative Commons palette、WaivOps Lo-Fi Drums 的 8 秒 source；指標含 FAD、spectral convergence、LSD、palette-index jitter、envelope correlation、RTF 與 chunked parity。

Findings

Beam 相對 greedy 約可將 palette-index jitter 減半並降低跨檔切換；RVQ-group 提供可聽的 structure/detail 控制；參考路徑在測試 palette 規模下可低於 realtime（RTF≈0.22–0.24）。Chunk 越大越接近 full-context 頻譜指標。

Limitations

證據以打擊／短促 onset 素材為主；和聲、人聲、長旋律需另調 gate 與 descriptor。客觀指標只作部署與連續性 sanity check，尚無正式聽感偏好測驗。

MeloBottleneck: Self-Supervised Melody Skeleton Extraction with a Latent Subsequence Bottleneck

自監督把旋律骨架當「長度可控、保序的 latent 子序列」：硬瓶頸選音＋節奏閉合成可獨立演奏的縮減旋律，跨域轉移優於偽標籤 note classifier。

可轉譯 melody skeleton symbolic MIDI self-supervised
Insight

洞見:karaoke-jp 的 MIDI／score 與 pitch 管線常被裝飾音、顫音、前倚音弄亂——真正需要的是「可當獨立旋律」的骨架，而不只是每個 note 的 keep/delete。MeloBottleneck 用 re-ornamentation 重建、凍結旋律 prior 與 ornament-invariant 目標學子序列，並在閉合時把刪除的時值吸回前一音，正好對齊 mora-to-note／導唱線簡化的工程需求：先縮結構，再對齊或渲染 LRC。

重要度

Problem

旋律骨架抽取若靠手寫規則或程序化 keep/delete 偽標籤，會繼承生成器偏差，且 note-wise 決策不等於「連貫的縮減旋律」。

Method

SimpleMono 表示（pitch／duration／delta-time）；Transformer 壓縮器做 top-K 保序子序列與可微 soft gather；rhythmic closure 產生零間隔閉合骨架；seq2seq re-ornamentation 重建；凍結 AR melody prior；程序裝飾視角上的 ornament-invariant consistency 與 exclusion loss。

Data

訓練聚合中英日歐等民間 monophonic 語料；評測含合成 OOD ornament-to-skeleton（O2B）、TAVERN variation-to-theme（V2T）、九宮工尺 ornamented-to-gongche（O2G）。補充材料：github.com/m-july/Supplementary-Files-For-MelobottleNeck-arXiv-Submission。

Findings

偽標籤分類器在合成 O2B 最強，但 MeloBottleneck 在 V2T／O2G 零樣本轉移更穩。骨架化 query 與 document 後，BM25 片段檢索 Recall@K 與 MRR 上升且查詢更快。去除 ornament exclusion 對插入音抑制傷害最大。

Limitations

僅 monophonic 符號旋律；評估多在 oracle 壓縮比下測選音，自由長度預測較弱。骨架定義依賴程序裝飾器，風格不匹配時不變性訊號可能失準。未做人聲聽感閉合品質獨立評測。
