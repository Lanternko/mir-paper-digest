Exploring Representation Autoencoders for Text-to-Audio Generation

把凍結的自監督音訊編碼器配上訓練過的解碼器當 latent 空間，再訓練 rectified flow；重建較差的空間，生成表現卻不輸傳統 VAE。

Insight

洞見:text-to-audio 選 latent 空間時，重建指標（如 FAD 重建、SNR）不是好的代理指標；語意結構更好的 SSL latent 讓 flow 更好學，這直接挑戰「先把 codec／VAE 重建做到最好」的慣例。

重要度

Problem

文字轉音訊（TTA）模型通常使用端到端以重建目標訓練的自編碼器作為 latent 空間；影像生成已證明「凍結預訓練編碼器 + 訓練解碼器」的 Representation Autoencoder（RAE）有效，但在音訊上很少被探討。

Method

作者替兩個預訓練的自監督（SSL）音訊編碼器訓練解碼器（稱為 AuRA），先比較其重建品質與近期 TTA 系統所用自編碼器；再於 SSL latent 與基線 latent 兩種空間各自訓練 rectified flow 模型，藉此隔離自編碼器對生成的影響。

Data

摘要與 abs 頁未點名兩個 SSL 編碼器與資料集（abs 頁只列出 5 位作者，另有 10 位未顯示）；細節需讀全文，本文未能解析 PDF，故不在此臆測。

Findings

在 SSL latent 空間中的生成表現與基線相當或更好，儘管其重建表現不同（較弱）。結論：「重建品質本身不足以作為生成表現的代理指標」。

Limitations

僅依摘要整理，未驗證具體數字、編碼器與評估設定；abs 頁未提供程式碼連結；是否能擴展到音樂（而非一般音訊）仍待確認。

Editor Note

與 MeanAudio 路線最直接相關：若 latent 好不好學比重建更重要，就值得重新檢視 MeanAudio 的 latent 選擇。作者清單在 abs 頁被截斷，此處僅列出前 5 位。

Structural Context from Audio and Lyric Evidence for Music Structure Analysis Using the New SheetSage-MSA Dataset

重要度

Problem

音樂結構分析（MSA）要找出段落邊界與功能標籤，但細粒度標註稀少、現有系統常用同一個編碼器同時做邊界與標籤，且多半只看音訊、忽略歌詞中的結構線索。

Method

提出 SCALE：用兩條各自任務專用的音訊路徑，分別建模局部轉換與長距離結構脈絡，並利用帶時間戳的歌詞與歌詞重複性來精修副歌預測。

Data

新建 SheetSage-MSA 資料集（源自 SheetSage）：9,010 首歌、13,880 筆清理後的片段標註，約 82.5 小時；於 HarmonixSet 評估。

Findings

在 HarmonixSet 上，相較 SongFormer，HR.5F 高 3.5 個百分點、HR3F 高 4.2 個百分點、ACC 高 0.9 個百分點；附有 demo 與原始碼頁面。

Limitations

僅 5 頁短文，摘要未提限制；歌詞時間戳來源與語言覆蓋（是否含日文）未知；結果只依摘要整理，未驗證全文。

Editor Note

不是 karaoke 專屬，但「時間戳歌詞 → 結構」正好是 karaoke-jp 管線的副產品，可遷移性高。
