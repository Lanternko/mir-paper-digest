MiDashengLM-Gen: Unified Audio Scene Generation via LLM-Driven Autoregressive Flow Matching

MiDashengLM-Gen 把預訓練 LLM 與 per-token 條件流匹配串成端到端混合音訊生成，英語 WER 從 12.15% 降到 2.79%，接近專用 TTS。

貼近主線 flow matching text-to-audio LLM
Insight

洞見:MeanAudio 若把「凍結文字編碼器 + 獨立音訊解碼器」當預設，跨模態無法聯合優化，混合場景裡的 intelligibility 常先崩。MiDashengLM-Gen（小米）把預訓練 LLM 與 per-token conditional flow matching 接成單一端到端序列：LLM 驅動、自回歸、可變長，一次生成同時含語音、音樂與音效的混合場景，並宣稱是首個以端到端訓練完成通用 text-to-audio 的此類路線。關鍵數字在可懂度：Seed-TTS 上英語 WER 從既有統一模型的 12.15% 降到 2.79%，逼近專用 TTS 的 1.24%；多語 WER 也具競爭力，MECAT 上混合音訊品質仍可維持。程式與權重已開源（GitHub / Hugging Face），demo 頁可聽。對 MeanAudio：這是「LLM 語義控制 + flow matching 聲學渲染」合一、且敢用 WER 硬指標打 intelligibility 的模板；若日後要在 JPOP／人聲曲裡保歌詞可懂度，混合場景端到端與 per-token CFM 都值得對標。

Try next

可做:把 MeanAudio 的文字條件從凍結 encoder 改成可微調 LLM 前綴，並在 codec／latent 上試 per-token CFM；用固定 caption 測日語歌詞／spoken 片段的 WER 與 CLAP，對照雙階段 TTS+混音基線。

重要度

Problem

現有混合音訊生成多採凍結、解耦的文字編碼器再餵獨立音訊解碼器，跨模態無法端到端優化，導致場景裡語音可懂度差、時間控制弱。

Method

提出 MiDashengLM-Gen：預訓練 LLM 與 per-token conditional flow matching 耦合，自回歸、可變長地端到端生成含語音／音樂／音效的混合音訊場景。

Data

Seed-TTS（英語 WER 等）、多語設定、MECAT 混合音訊品質；code/checkpoint：github.com/xiaomi-research/midashenglm-gen、huggingface.co/mispeech/midashenglm-gen；demo：xingws.github.io/midashenglm-gen-demo/。

Findings

相對既有統一模型，Seed-TTS 英語 WER 12.15%→2.79%，接近專用 TTS（1.24%）；多語 WER 具競爭力；MECAT 混合生成品質仍維持競爭水準。

Limitations

主報告偏語音 intelligibility 與混合場景，非純音樂／日語 JPOP 專項；長曲結構與歌詞—旋律對齊未在摘要展開；開源權重的授權與訓練資料細節需自行核對。

Editor Note

MeanAudio 本週核心模板：端到端 LLM + per-token flow matching，用 WER 把「混合場景可懂度」拉到接近專用 TTS。

MusicLayout: Explicit Structural Planning for Controllable Text-to-Music Generation

MusicLayout 在文字與音訊 token 之間插入可檢視／可改的段落—織體—樂器時間對齊佈局，讓 text-to-music 的長程結構先規劃再生成。

貼近主線 text-to-music structure control layout planning
Insight

洞見:昨日 FullDiT 談的是「從不完美離散 plan 做全上下文渲染」；今天 MusicLayout 補上另一半——plan 本身該長什麼樣、能不能在出聲前被改。多數 TTM 只靠全局文字 prompt，段落、織體、重複／變奏與樂器編排都隱式擠在模型裡，難檢查也難局部修。MusicLayout 定義時間對齊的中間表示：section、texture、repetition／variation、instrument-level arrangement，作為文字意圖與音訊之間的可解釋規劃層；在統一自回歸框架裡先生成 layout，再條件化預測音訊 token，且生成後的 layout 可在出聲前檢視與修改。評估含 layout 條件生成、layout 操控實驗與 matched-data 消融，證據指向顯式佈局有助長程結構與 layout 級控制。實作已開源（XaryLee/MusicLayout）。對 MeanAudio：可當 hybrid／AR 管線的「可編輯結構 plan」介面，與 FullDiT 的 codec plan 疊加時，先定段落與配器再渲 latent，會更適合整曲與人聲段落排程。

Try next

可做:為 MeanAudio 定義精簡 layout schema（段落起迄、人聲有無、主奏樂器），先 LM 吐 layout 再條件生成；A/B 比較「僅 caption」vs「caption+layout」的段落邊界與重複結構穩定性。

重要度

Problem

Text-to-music 多依賴全局文字提示，結構組織隱式且難以在生成音訊前檢視、控制或修訂。

Method

提出 MusicLayout 中間表示（段落、織體、重複／變奏、樂器編排的時間對齊佈局）；統一自回歸模型先生成 layout，再條件化生成音訊 token，並支援出聲前修改 layout。

Data

layout 條件生成、layout 操控實驗、matched-data 消融；開源：github.com/XaryLee/MusicLayout。

Findings

顯式 layout 規劃可改善長程結構組織，並支持 layout 層級的可控編輯；消融與操控實驗提供結構控制證據。

Limitations

摘要未給大規模聽感／自動指標全表；layout 標註或偽標成本、對日語歌詞段落的語意約束未詳述；與 diffusion／flow 渲染器的介面需另接。

Editor Note

接續 FullDiT：先讓結構 plan 可讀可改，再談渲染對齊——TTM 可控性的「規劃層」補丁。
