P-MUSE: Prompt-MIDI-Optional Model for Unified Instrumental Music Synthesis and Editing

把「僅 prompt 音」與「prompt+MIDI ICL」兩種 MIDI-to-Music 范式用課程學習統一起來，並以 fill-in-the-middle 同時涵蓋生成與局部編輯。

貼近主線 MIDI-to-music music editing prompt conditioning
Insight

重要度

Problem

現有 MIDI-to-Music 系統通常只能選一種范式：僅用 prompt 音做條件生成（缺對齊 MIDI 時可用，但控制較弱），或用成對 prompt 音＋MIDI 的 in-context learning（控制強，卻依賴對齊 MIDI）。兩者分裂，且生成與局部編輯也常分成不同管線。

Method

P-MUSE：instrumental MIDI-to-Music 框架，以 multi-stage curriculum learning 支援 prompt-MIDI-optional 輸入，統一「僅 prompt」與「prompt+MIDI ICL」；以共享的 fill-in-the-middle 表述同時涵蓋音樂生成與局部編輯；並提出 Transcription-to-Audio 的 phase-aware classifier-free guidance 排程原則與 Tail-Drop 策略。

Data

建立涵蓋多種 prompt 模式、生成／編輯任務與四類代表性樂器（piano、guitar、bass、drums）的綜合 benchmark；demo 於 https://p-muse.github.io/。具體訓練集規模與授權以原文為準。

Findings

統一模型可在 prompt 可選 MIDI 條件下維持 MIDI following 與音色相似度；fill-in-the-middle 使生成與局部編輯共用配方；phase-aware CFG 與 Tail-Drop 經理論與實證支持。

Limitations

目前聚焦 instrumental MIDI-to-Music，未涵蓋唱聲／歌詞對齊生成；四樂器 benchmark 是否覆蓋 JPOP 編曲慣例需另驗；權重與完整訓練配方公開程度以專案頁為準。

Editor Note

MeanAudio 今日首選：條件完備度不固定時，別再為「有／無 MIDI」各養一套模型。curriculum + FITM 編輯是可直接抄的產品化模板。

Separate-and-Detect: Unified Drum Transcription and Stem Generation via Latent Diffusion

重提 separate-and-detect：五軌鼓 stem 的 latent diffusion 分離器＋固定 onset 偵測，同時交出可編輯 stem 與符號轉寫。

MIR 觀點 drum transcription source separation latent diffusion
Insight

洞見:自動鼓轉錄若只從混合音直接映射到符號，會丟掉 remix／production 真正需要的可編輯 stem。本文把 ADT 拉回「先生成五軌鼓 stem，再固定 detector 轉 onset」——生成式 demixing 當可解釋前端，而不是黑盒 event 分類。對 karaoke-jp／製作管線的啟發是：分離與轉錄不該是兩套互不溝通的模型，onset／timbre 輔助分支只在訓練期塑形、推理丟掉，也是可遷移的設計。

重要度

Problem

Automatic Drum Transcription 常被做成混合音→符號事件的直接映射，雖有轉錄分數，卻捨棄對編輯、remix 與製作有用的聲學 stem。

Method

separate-and-detect：五 stem latent diffusion 分離器（kick、snare、toms、hi-hats、cymbals）在緊湊 VAE latent 空間聯合生成；固定 onset detector 將各 stem 轉成符號事件。訓練期另加 onset branch（OB）與 timbre branch（TB）塑形分離器，推理時丟棄。

Data

在合成鼓 multitrack 上訓練；於 MDB Drums 與 ENST-Drums 評估。ISMIR 2026 accepted。

Findings

相對強 U-Net 鼓分離 baseline，整體轉錄 F1 一致提升；在評估協議下 kick／snare F1 也優於代表性端到端 ADT，同時額外提供分離音軌。消融顯示 OB 對轉錄增益最穩，TB 則牽動重建、stem 品質與 onset 偵測的權衡。

Limitations

訓練以合成鼓 multitrack 為主，真實現場／多層 sample 鼓組 domain gap 需另測；目前僅鼓組，未擴到人聲或全頻 MSS；代碼／權重公開狀態以論文後續為準。

Editor Note

ISMIR 2026 鼓線：生成式 demixing 可以同時當 separation 與 transcription 前端。別只追 F1——可編輯 stem 才是產品價值。
